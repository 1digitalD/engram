Annotations

  • 1The capture line is permanent chrome and summonable with one keystroke from any surface. No fields, no filing — type, enter, done (see Mockup 2).
  • 2The Pulse: a persistent one-line answer to “is AI doing something right now?” Expands into a peek panel; clicks through to Review/Ledger. The violet ✦ accent is used only for AI activity, app-wide.
  • 3Left column = things only the human can resolve. The two-column split is the trust model made spatial: my attention vs. delegated motion.
  • 4A blocked agent question is the highest-priority card type — a waiting agent is wasted leverage. Answerable inline with one click.
  • 5Proposals are digested here, actioned in Review (Mockup 3) or inline where they occur. Consequential changes (create/status/merge) never auto-apply.
  • 6Staleness surfaces as a human decision — keep/drop/delegate — not as silent AI cleanup.
  • 7Right column = leverage at work. Live run cards, not a notifications tray.
  • 8Every run is interruptible from wherever it's visible (glass-box rule 7).
  • 9Auto-applied annotations arrive as a digest with in-place undo — reviewable without being blocking. Full history lives in the Ledger.
  • 10Resurfacing: recall that comes to you. Read-only and dismissible — never a proposal, never files anything.
