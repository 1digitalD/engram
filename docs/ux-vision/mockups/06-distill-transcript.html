Annotations

  • 1The transcript stays an immutable Stream entry. The report is structure derived around it — the source is one click away from every extracted line, forever.
  • 2Owner accuracy is what makes accountability work, so speaker identity gets a first-class question — one crisp ask, not a silent guess.
  • 3A multi-topic meeting routes to multiple Spaces; each Space's spine receives only its slice. Routing is annotate-tier: applied, marked, undoable.
  • 4Reconciliation before creation: updates about existing work attach to it. Pure progress-logging is auto (undoable); anything that changes state (mark done) is a proposal diff.
  • 5Commitments are extracted with owner + due-ish + the quoted words that created them. Yours become tasks…
  • 6…others' become waiting-ons — the unit of accountability. Accepting one arms the follow-up engine: it ages visibly, ripens onto Today with a receipt-based nudge draft, and closes automatically when a later capture shows delivery.
  • 7Near-duplicates become explicit one-click questions rather than silent merges or silent twins. Shown dedup is what lets the user stop double-checking for redundancy.
  • 8Decisions are first-class records with participants, quote, and supersession links — the Space's decision log answers “why did we decide X?” months later.
  • 9What the distiller ignored is visible but collapsed — “set aside” must never read as “missed.” Expanding and rescuing something trains the distiller.
  • 10Batch-accept covers only high-confidence lines; the reconciliation question and the speaker question always require an explicit human answer. Target: one meeting, one minute.
